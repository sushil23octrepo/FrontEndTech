"# UI" 
Step 1: Setup react app with typescript template
npx create-react-app react-mui --template typescript

Step 2: Install MUI package
npm install @mui/material @emotion/react @emotion/styled

Step 3: Install material ui icon library for icons.
npm install @mui/icons-material

Step 4: material ui date picker and other date functions
npm install date-fns @date-io/date-fns

step5: material UI lab controls e.g. loading button
npm install @mui/lab
